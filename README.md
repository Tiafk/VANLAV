# 🍰 VANLAV — Многостраничный сайт франшизы кондитерской

Полноценный многостраничный веб-сайт для франшизы фиолетовых кондитерских **Vanlav**. Проект включает главную страницу, разделы о компании, каталог кондитерских, доставку, вакансии и правовую информацию. Сайт разработан с упором на производительность, SEO и впечатляющий визуальный опыт.

🔗 **Демо-версия**: [https://tiafk.github.io/VANLAV/](https://tiafk.github.io/VANLAV/)
🌐 **Официальный сайт проекта**: [vanlav.ru]([https://vanlav.ru](https://vanlav.ru/franchise.html))

## ✨ Особенности проекта

- **Многостраничная архитектура**: логичная структура из 6+ страниц (`index`, `about`, `confectionery`, `delivery`, `vakancy`, `poly`) с единым стилем и навигацией.
- **Полностью адаптивная и кроссбраузерная вёрстка**: пиксель-перфект отображение и корректная работа на десктопных, планшетных и мобильных устройствах (включая адаптивное бургер-меню).
- **Модульная структура кода**: использование SCSS/SASS с разделением стилей и скриптов на логические файлы для упрощения поиска, поддержки и масштабирования проекта.
- **Продвинутые анимации и интерактив**: 
  - Анимированные SVG-линии с эффектом рисования (`stroke-dasharray`).
  - Параллакс-эффекты для фоновых изображений.
  - Плавные слайдеры на базе библиотеки **Swiper.js**.
  - Бегущие строки (marquee-эффект) для динамичного контента.
- **Оптимизация производительности**: предварительная загрузка ключевых ресурсов (`<link rel="preload">`), ленивая загрузка изображений (`loading="lazy"`), использование современных форматов (`.webp`).
- **SEO и доступность**: семантическая HTML5-разметка, микроразметка Schema.org (JSON-LD), метатеги Open Graph и Twitter Cards, наличие `robots.txt` и `sitemap.xml`.

## 🛠️ Используемые технологии

- **HTML5** (семантическая разметка, доступность, микроразметка)
- **SCSS / SASS** (препроцессор для организации и компиляции стилей)
- **CSS3** (Flexbox, Grid, сложные анимации, медиа-запросы)
- **JavaScript (Vanilla JS)** (логика меню, слайдеров, параллакса и форм)
- **Swiper.js** (современная библиотека для создания тач-слайдеров)
- **intl-tel-input** (библиотека для маски и ввода международных телефонных номеров)

## 📁 Структура проекта

```text
VANLAV/
├── css/                # Скомпилированные CSS файлы
├── scss/               # Исходные SCSS файлы, разбитые по модулям/блокам
├── img/                # Графические ресурсы (включая оптимизированные .webp и SVG)
├── fonts/              # Шрифты проекта
├── video/              # Видеофайлы для фона или контента
├── index.html          # Главная страница
├── about.html          # Страница "О проекте"
├── confectionery.html  # Страница "Кондитерские"
├── delivery.html       # Страница "Доставка"
├── vakancy.html        # Страница "Вакансии"
├── poly.html           # Страница с политикой конфиденциальности
├── app.js              # Основная логика (главная страница)
├── about.js            # Логика страницы "О проекте" (слайдеры)
├── vacancy.js          # Логика страницы "Вакансии"
├── location.js         # Скрипт для работы с данными о локациях
├── location.json       # JSON-данные о точках присутствия
├── robots.txt          # Инструкции для поисковых роботов
└── sitemap.xml         # Карта сайта для SEO-индексации
```
